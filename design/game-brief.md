# Godot 迁移试玩 · 0.3.0 电脑输入

2026-10-06。用户选择 Godot＋GDScript，目标 Steam 与网页；原网页项目及已发布页面保持不变，另建独立仓库。

0.1.1 已完成原生大地图、城池与战斗视图、建设/训练/任务/出征主要操作、本地存档兼容、Windows 与网页导出，以及相同规则 API 验证。0.2.0 已发布市场交易、城守与税率管理、客栈招募，使建设、补给和出征形成经营循环。0.3.0 已实现动作抽象的电脑输入、键盘地图导航与可保存的重绑设置；482 项本地检查、原生桌面重绑/重启恢复/地图操作及实际 Web 桌面/390 窄屏输入已通过，最终 Windows/Web 导出成功，正式发布与 Windows 发布包启动 CI 待完成。见 `production/epics/godot-client/story-003-pc-input.md` 和 `docs/QA.zh.md`。Steamworks 接入在客户端验证之后。

本轮输入覆盖五个主页面、事务、存档、设置、地图平移、缩放和回城。冲突、保留按键与保存失败有明确反馈，配置与游戏进度分离；文字编辑、弹窗和失去窗口焦点时暂停游戏快捷键，Tab/Enter/Esc 保留原生控件操作，鼠标和触屏入口仍可用。后续按 `docs/PC-GAMES.zh.md` 建立性能基线，继续其余管理和完整名将/招降、联盟与计谋，再规划正式美术与各州扩容；本轮不调整英雄技能或经济平衡。

风格：写实古代战争，以暗炭、铜金、青灰城墙与连续地形为主；画面用可扩展原生绘制，避免原网页格子列表。地图支持跟手拖动、锚点缩放、军队路线/到达时间、远近层级；规则世界维持 64×64，后续各州扩容需要独立规则与存档迁移。

桌面打包本地 Node 规则服务与完整资源，GDScript 负责客户端，JavaScript 规则快照负责原作结算。网页通过相同 API 连接服务；正式共享多人仍需要带账号与服务端权威存档的部署，不将本地桥接直接暴露公网。
