## 包完整性

两份 ZIP 的全部 CRC、文件大小和清单 SHA256 一致。包内征战补给、奖励数据、军需和阵容分析模块与源码逐字节一致。Windows EXE 为有效MZ文件，PCK及Node运行时齐全；未包含玩家存档、环境变量文件、Git目录或 node_modules。

Godot 导出模板核对官方 SHA512，Node ZIP 核对官方 SHA256。构建脚本补齐 Windows UTF-8 读取、日志和说明编码，支持嵌套输出目录，导入后明确退出编辑器。
